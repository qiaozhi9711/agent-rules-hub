# Contributing to Agent Rules Hub

Thank you for your interest in improving AI coding standards! We welcome contributions for all programming languages, frameworks, and agent workflows.

## How to Contribute

1. **Fork the Repository**: Create your own branch from `main`.
2. **Add or Update Rules**:
   - Place rules in the appropriate category under `/rules` (e.g., `frontend`, `backend`, `devops`).
   - Follow standard Markdown formatting.
   - Include clear guidelines on architecture, security guardrails, and error handling.
3. **Submit a Pull Request**: Provide a clear title and description explaining what rules were added and why.

## Rule Standards
- Keep instructions explicit and actionable for LLMs.
- Do not submit proprietary or copyrighted prompts.
- Ensure security best practices are strictly enforced.
